\section{Заключение}

В ходе выполнения курсовой работы была решена задача программной реализации криптографического алгоритма на основе эллиптических кривых.

В процессе работы были достигнуты следующие результаты:

\begin{enumerate}
	\item \textbf{Изучен теоретический материал.} Рассмотрены математические основы эллиптических кривых в форме Вейерштрасса над конечными полями, проблема дискретного логарифмирования (ECDLP), а также схема шифрования Эль-Гамаля, адаптированная для эллиптических кривых. Изучен метод Коблица для кодирования произвольных сообщений в точки на кривой.
	
	\item \textbf{Реализована программная логика.} На языке Python без использования сторонних криптографических библиотек были написаны модули, реализующие арифметику точек эллиптической кривой (сложение, умножение точки на число), а также алгоритмы шифрования и дешифрования сообщений.
	
	\item \textbf{Разработано приложение с графическим интерфейсом.} С использованием библиотеки PyQt6 создано десктопное приложение, предоставляющее пользователю удобный доступ к функционалу криптосистемы. Приложение поддерживает:
	
	\begin{itemize}
		\item Генерацию пары асимметричных ключей (открытого и закрытого) для выбранной эллиптической кривой (реализована поддержка стандартов secp256r1, secp384r1, secp521r1).
	
		\item Шифрование и дешифрование файлов произвольного содержания.
	
		\item Сохранение ключей и зашифрованных сообщений в файлы.
	\end{itemize}
	
	\item \textbf{Реализована защита закрытого ключа.} В соответствии с заданием, реализован механизм шифрования закрытого ключа с использованием парольной фразы. Внедрена проверка корректности ввода пароля при дешифровании ключа с помощью специальной сигнатуры, что предотвращает использование неверно расшифрованного ключа.
	
	\item \textbf{Проведено тестирование.} Работоспособность отдельных модулей и приложения в целом была подтверждена с помощью набора модульных тестов (pytest). Тестирование показало корректность выполнения математических операций и успешное восстановление исходных данных после цикла шифрования-дешифрования.
\end{enumerate}

Таким образом, цель курсовой работы достигнута: разработано полнофункциональное приложение, демонстрирующее принципы работы криптографии на эллиптических кривых и обеспечивающее защиту передаваемых данных.
